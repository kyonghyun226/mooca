# MOOCA

반려동물 컴패니언 스튜디오 **MOOCA** 소개 사이트입니다.
태그라인: *My One and Only Companion Animal*

A single-page intro for MOOCA — a Korean companion-animal photo studio currently building an app.

## 로컬 실행 / Run locally

```bash
npm install
npm run dev
```

브라우저에서 Vite가 안내하는 주소(기본 `http://localhost:5173`)로 접속하세요.

## 빌드 / Build

```bash
npm install
npm run build
```

정적 결과물은 `dist/`에 생성됩니다. 미리 보려면:

```bash
npm run preview
```
