# MOOCA · 모카

STUDIO MOOCA 소개 사이트입니다. 사진 스튜디오와 준비 중인 앱을 한 페이지로 안내합니다.

A single-page intro site for **MOOCA** (모카), a Korean photo studio currently building an app.

## 로컬 실행 / Run locally

```bash
npm install
npm run dev
```

브라우저에서 Vite가 안내하는 주소(기본 `http://localhost:5173`)로 접속하세요.

## 빌드 / Build

```bash
npm install
npm run build
```

정적 결과물은 `dist/`에 생성됩니다. 미리 보려면:

```bash
npm run preview
```
